# Лабораторная работа № 5 — поиск, сортировка, подбор

Пять функций на C++17 без внешних зависимостей: стабильная сортировка по уровню важности, фильтрация по компоненту, поиск максимального конечного значения указанного параметра, выбор показаний от заданного уровня важности.

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Компьютерные тесты находятся в `tests/test_algorithms.cpp`. Поле `severity` — учебный ранг (0,1,2), его соответствие правилам диагностики должно задаваться модулем обработки данных. Алгоритмы не заменяют PostgreSQL и не являются реализованной интеграцией с ЛР №4.
