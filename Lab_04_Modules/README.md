# Лабораторная работа № 4 — разработка модулей SpaceTrainerMonitor

## Состав
- `EquipmentSimulator` отправляет JSON по TCP каждые 1 с; четырёхбайтовый big-endian заголовок содержит длину пакета.
- `TelemetryServer` принимает поток TCP, выделяет сообщения и валидирует числовые поля.
- `MainWindow` отображает показания напряжения и предупреждения.
- `DatabaseManager` при подключении сохраняет измерения в БД из ЛР №3.

## Сборка
Требуются Qt 6 (Widgets, Network, Sql), CMake 3.21+, компилятор C++17.

```powershell
cmake -S . -B build -DCMAKE_PREFIX_PATH="C:/Qt/6.x.x/mingw_64"
cmake --build build
```

Путь Qt и генератор сборки необходимо подставить согласно установленному комплекту Qt Creator; на MSVC используется соответствующий комплект Qt.

## Запуск
1. Подключить PostgreSQL 17, выполнить скрипты ЛР №3 (только один раз для чистой базы).
2. Запустить приложение из Qt Creator; нажать «Запустить имитатор».
3. При необходимости нажать «Подключить PostgreSQL», ввести пароль локального пользователя `postgres`.
4. Проверить появление значений и периодических предупреждений, затем `SELECT * FROM measurements ORDER BY id DESC LIMIT 10;`.

**Важно:** демо использует учебные `component_id=3`, `parameter_id=4` и пороги 22–26 В; предполагается, что в чистой БД выполнен `02_test_data.sql`. Это не реальные инженерные нормы. Данное приложение не осуществляет полную обработку диагностических правил, не регистрирует автоматически `diagnostic_events` и не является готовым промышленным решением.

Пароль БД не хранится в исходниках. Пользователь проверил сборку и запуск на Windows 28.10.2026: приём TCP, вывод предупреждения и запись измерений в PostgreSQL подтверждены снимками экрана. После исправления кода повторного подключения требуется пересборка и повторная проверка кнопки «Подключить PostgreSQL».

## Подготовка PostgreSQL на Windows
В случае ошибки QPSQL сначала проверить, что служба PostgreSQL запущена; для Qt Creator, запущенного из CMD, временно добавить каталог PostgreSQL в PATH:

```bat
set "PATH=C:\Program Files\PostgreSQL\17\bin;%PATH%"
start "" "C:\Qt\Tools\QtCreator\bin\qtcreator.exe"
```

В Qt Creator открыть CMakeLists.txt, выбрать Desktop Qt 6.12 MinGW 64-bit и собрать Ctrl+B.
