

\# СООТВЕТСТВИЕ ФУНКЦИОНАЛЬНЫХ ТРЕБОВАНИЙ ПРОГРАММНЫМ МОДУЛЯМ



\## 1. Назначение документа



Настоящий документ устанавливает соответствие между функциональными требованиями подсистемы SpaceTrainerMonitor и программными модулями, ответственными за их реализацию.



Таблица соответствия предназначена для обеспечения прослеживаемости требований на этапах проектирования, разработки и тестирования программного обеспечения.



\## 2. Матрица соответствия



| Идентификатор | Функциональное требование | Ответственный модуль |

|---|---|---|

| FR-01 | Получение данных | NetworkManager |

| FR-02 | Идентификация компонентов | MonitoringManager |

| FR-03 | Мониторинг состояния | MonitoringManager |

| FR-04 | Контроль допустимых значений | DiagnosticsManager |

| FR-05 | Диагностика неисправностей | DiagnosticsManager |

| FR-06 | Регистрация событий | DiagnosticsManager, DatabaseManager |

| FR-07 | Хранение данных | DatabaseManager |

| FR-08 | Просмотр истории | DatabaseManager, MainWindow |

| FR-09 | Поиск и фильтрация | DatabaseManager, MainWindow |

| FR-10 | Уведомление оператора | MainWindow |

| FR-11 | Отображение состояния подключения | NetworkManager, MainWindow |

| FR-12 | Работа с имитатором | EquipmentSimulator, NetworkManager |



\## 3. Использование матрицы



Матрица соответствия применяется при распределении задач разработки между программными модулями.



При реализации системы каждому функциональному требованию должны соответствовать программный компонент и один или несколько тестовых сценариев.



Изменение функциональных требований должно сопровождаться проверкой необходимости корректировки архитектуры и состава программных модулей.



\## 4. Заключение



Сформированная матрица обеспечивает прослеживаемость функциональных требований и определяет основу для последующей реализации и тестирования подсистемы мониторинга и диагностики компонентов космического тренажёра.
