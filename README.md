\# SpaceTrainerMonitor



Разработка подсистемы мониторинга и диагностики компонентов космического тренажёра.



\## Технологии

\- C++17

\- Qt 6

\- PostgreSQL

\- TCP/IP

\- CMake

\- Git



\## Структура проекта

\- Lab\_01\_Git — работа с Git.

\- Lab\_02\_Requirements — технические требования.

\- Lab\_03\_Database — проектирование базы данных.

\- Lab\_04\_Modules — разработка модулей.

\- Lab\_05\_Algorithms — алгоритмы поиска и сортировки.

\- Lab\_06\_Testing — тестирование.

\- Final\_Project — итоговая версия подсистемы.



\## Целевая платформа

Разработка осуществляется на Windows с учётом последующего переноса на Astra Linux.
